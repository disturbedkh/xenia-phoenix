# Battlefield 2: Modern Combat (`454107DB`)

> **STATUS: PARKED (workaround)** — Active work is smoke roster + patch backlog + [edge_port_queue.md](../../plan/edge_port_queue.md). Revisit when [bf2_gpu_roadmap.md](../../plan/bf2_gpu_roadmap.md) § Parked triggers are met. No new BF2 sessions or src changes until then.

## Summary

Kernel stub drain **resolved** on Phoenix (phoenix marker only in stubs JSONL). **Edge (user 2026-05-16):** [compat #9 kortul](https://github.com/xenia-canary/game-compatibility/issues/9#issuecomment-3997637068) workaround **still fixes** ground flicker; **secondary shadow** after fix remains (G-454107DB-004). Boot FMV, loading → main menu, and mission-load A/V **work** on Edge; **in-mission audio loss + crash** and **random rainbow sky rays** still open. **Phoenix:** ground flicker on defaults + after U-GPU-001 v3 (mismatch 0, visual fail); kortul parity on Phoenix **not yet run**. Roadmap: [bf2_gpu_roadmap.md](../../plan/bf2_gpu_roadmap.md).

Engines: EAGL + RenderWare (compat labels).

## Launch (instrumented)

```powershell
cd xenia-phoenix-src
powershell -File tools/tier0/bf2_gpu_session.ps1 -Launch
# After F4 at repro + quit:
powershell -File tools/tier0/bf2_gpu_session.ps1 -PostOnly -Triage
phoenixctl guard check --title-id 454107DB --json
```

Or manually: `phoenixctl launch triage --title-id 454107DB --game "<iso>" --fresh` then `phoenixctl repro capture --post-only --json`.

**Observability v2:** triage launches use `--log_preset=develop` and unified `telemetry/454107db_events.jsonl`. After quit, post scripts write `telemetry/454107db_obs_summary.json` with classification (e.g. U-GPU-001 / G-454107DB-003 from invariant codes). One-screen summary: `phoenixctl log summarize --title-id 454107DB --write-summary`. See `metacache/dev/observability.md`.

Default triage: `--readback_resolve=fast`, `--apu=xaudio2`, `--hid=xinput`, telemetry paths.

**Controller:** Double-clicking `xenia_canary.exe` uses saved config; older builds default `hid=any`, which **skips XInput** on Windows (only SDL + keyboard). Use `tools/tier0/play_bf2.ps1` or `launch_bf2_triage.ps1`, or set `hid = "xinput"` in `%USERPROFILE%\Documents\Xenia\xenia-canary.config.toml`, or pass `--hid=xinput` on the command line. Rebuild after 2026-05-17 changes default `hid` to `xinput` on Windows (config file still overrides).

Optional in-game only — **proven on Edge**, verify on Phoenix ([G-454107DB-010](#g-454107db-010-edge-kortul-parity--fork-delta); [compat #9 kortul](https://github.com/xenia-canary/game-compatibility/issues/9#issuecomment-3997637068)) when `PHOENIX_BF2_GFX_WORKAROUND=1`:

- `--depth_float24_convert_in_pixel_shader=true`
- `--gpu_allow_invalid_upload_range=true`

Telemetry: `telemetry/454107db_*`, GPU traces under `telemetry/454107db_gpu_trace/`. **F4 at in-game repro**, not loading screen only.

## Workarounds in use

| Cvar / flag | Why | Retire when |
|-------------|-----|-------------|
| `depth_float24_convert_in_pixel_shader=true` | Align PS depth with 20e4 after precision loss | U-GPU-001 fixed in src |
| `gpu_allow_invalid_upload_range=true` | On **Edge**, avoids batch abort on stale range; on Phoenix often redundant (continue-upload) | U-GPU-002 fixed or parity confirmed |
| `PHOENIX_BF2_GFX_WORKAROUND=1` | In-game ground flicker only | Menu freeze/halo risk if set at boot |
| `readback_resolve=fast` | Triage default; not halo fix | — |
